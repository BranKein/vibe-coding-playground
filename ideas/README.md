# 아이디어 모음

바이브 코딩 프로젝트의 아이디어와 요구사항을 적어두는 곳이다. 여기 적힌 것은 구현 약속이 아니라 후보다.

## 목록

| 아이디어 | 상태 | 한 줄 설명 |
|---|---|---|
| [프로젝트 박물관 사이트](project-museum-site.md) | 보류 | 루트 저장소의 정적 사이트로 하위 프로젝트들을 전시 |

## 작성 규칙

- 아이디어 하나에 파일 하나. 파일명은 영문 kebab-case (`project-museum-site.md`).
- 사용자가 말한 내용과 에이전트가 덧붙인 제안을 구분해서 적는다. 사용자가 말하지 않은 것은 "미정" 또는 "제안"으로 표시한다.
- 파일을 추가하거나 상태가 바뀌면 위 목록을 갱신한다.

## 상태 값

- **아이디어**: 적어만 둔 상태
- **보류**: 하기로 했지만 지금은 아님
- **구현 중**: 저장소를 만들고 서브모듈로 연결함
- **완료**: 동작하는 결과물이 있음
- **폐기**: 하지 않기로 함

## 파일 형식

```markdown
# 제목

- 상태: 아이디어
- 작성일: YYYY-MM-DD
- 저장소: (구현 시작 후 링크)

## 개요
## 요구사항
## 미정 사항
## 메모
```
