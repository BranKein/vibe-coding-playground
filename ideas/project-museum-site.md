# 프로젝트 박물관 사이트

- 상태: 보류 (다른 프로젝트들이 생긴 뒤에 진행)
- 작성일: 2026-10-12
- 저장소: 별도 저장소 없음. 루트 저장소(vive-coding-playground)에 직접 만든다.

## 개요

루트 저장소에 정적 사이트를 하나 만들어, 서브모듈로 참조하는 바이브 코딩 프로젝트들을 박물관처럼 전시한다.

## 요구사항

사용자가 말한 내용:

- 정적 사이트일 것
- 루트 폴더에 위치할 것
- 다른 프로젝트들을 보여줄 것
- 박물관 같은 느낌일 것

## 미정 사항

- 사이트 생성 도구와 기술 스택
- 배포 위치
- 프로젝트별로 보여줄 정보 (설명, 스크린샷, 데모 링크, 저장소 링크 등)
- 전시 목록을 어디서 가져올지 (`ideas/` 문서, 서브모듈 목록, 별도 데이터 파일 등)
- "박물관 느낌"의 구체적인 디자인 방향
- 구현 전인 아이디어도 전시할지 여부

## 메모

- 제안: 각 아이디어 파일의 상태·저장소 항목을 일정하게 유지해 두면, 나중에 이 사이트가 그 값을 읽어 전시 목록을 만들 수 있다.
