# 주기적 코딩 문제 생성 및 구독 알림

- 상태: 아이디어
- 작성일: 2026-10-12
- 저장소: (구현 시작 후 링크)

## 개요

일정 주기마다 코딩 테스트 문제나 SQL 문제를 LeetCode처럼 간단히 만들어 쌓아두고, 목록으로 보거나 검색할 수 있게 한다. 이메일을 등록한 구독자에게는 문제가 추가될 때마다 메일로 알린다.

## 요구사항

사용자가 말한 내용:

- 일정 주기에 한 번씩 문제를 자동으로 만든다.
- 문제 종류는 코딩 테스트 문제 또는 SQL 문제다.
- 문제는 LeetCode처럼 간단한 형태다.
- 만든 문제를 리스트로 저장하고, 목록 조회와 검색이 가능해야 한다.
- 구독 기능이 있다. 사용자가 본인 이메일을 등록한다.
- 문제가 추가될 때마다 구독자에게 메일 알림을 보낸다.

## 미정 사항

- 문제 생성 주체와 방식 (LLM 생성, 미리 만든 문제 풀에서 추출 등)
- 생성 주기 (매일, 매주 등)와 한 번에 만드는 문제 수
- 코딩 문제와 SQL 문제의 비율, 난이도 구분 여부
- 문제에 포함할 항목 (설명, 예시 입출력, 제약 조건, 정답·해설, 태그 등)
- 사이트에서 답안을 제출·채점하는지, 문제만 보여주는지
- 검색 기준 (제목, 태그, 난이도, 종류 등)
- 구독 시 이메일 인증 여부와 구독 해지 방법
- 구독 옵션 (문제 종류별 구독, 알림 묶음 발송 등)
- 메일 발송 수단과 저장소·호스팅 방식
- 생성된 문제의 품질·중복 검증 방법

## 메모

- 제안: 구독 해지 링크는 메일마다 넣는 것이 좋다. 본인 확인 없이 이메일을 등록할 수 있으면 타인의 주소로 메일이 나갈 수 있으므로, 확인 메일(더블 옵트인)을 거치는 편이 안전하다.
- 제안: 정적 사이트와 예약 작업(예: 스케줄된 CI) 조합으로도 문제 생성·목록·검색까지는 구현할 수 있다. 구독자 이메일 저장과 발송에는 별도 서비스가 필요하다.
