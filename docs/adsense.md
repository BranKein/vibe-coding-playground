# 광고 (Google AdSense)

공개 웹 프로젝트에 광고를 붙일 때 읽는다. 2026-10-20에 박물관과 `warehouse-tycoon`에 처음 붙였다.

## 구조

- 애드센스 계정 하나, 등록 사이트는 루트 도메인 `yeonhyuk.me` 하나다. 애드센스는 하위 도메인을 따로 등록받지 않고, 루트가 승인되면 하위 도메인에도 광고가 나온다.
- 루트 사이트(`projects/home`)가 애드센스 소유 확인 메타 태그(`google-adsense-account`)와 `ads.txt`를 낸다. `ads.txt`는 하위 도메인 광고까지 인증한다. 루트 사이트 자체에는 광고가 없다.
- 게시자 ID: `ca-pub-6463808305479933`.

## 프로젝트에 광고 칸 붙이기

- **자동 광고는 쓰지 않는다.** 칸을 직접 만든다(사용자 결정). 애드센스 화면의 자동 광고도 꺼 둔다.
- **환경 변수로만 켠다.** `ADSENSE_CLIENT`(게시자 ID)와 칸마다 `ADSENSE_SLOT_<이름>`(광고 단위 ID)이 빌드 환경(GitHub Variables)에 있을 때만 스크립트와 칸을 넣는다. 없으면 화면이 광고 전과 똑같아야 한다.
- **스크립트는 칸이 있는 페이지에만** 넣는다.
- **"광고 · Ad" 표시**를 칸에 붙여 콘텐츠와 헷갈리지 않게 한다.
- **게임·캔버스 화면 위에 겹치지 않게** 한다. 게임은 화면 옆(사이드바)에 두고, 클릭할 수 있는 게임 UI와 16px 이상 띄운다(실수 클릭 정책). 좁은 화면·터치 기기에서는 숨긴다.
- **비어 있거나 차단돼도 레이아웃이 깨지지 않게** 한다. `push()`는 try/catch, 채워지지 않은 칸은 숨긴다.
- 개인정보처리방침은 루트 사이트의 `privacy.html` 하나를 쓴다. 광고를 붙인 사이트 꼬리말에서 링크한다.

## 현재 상태와 승인 뒤 할 일 (2026-10-20)

**지금 상태**
- `yeonhyuk.me`(home v0.0.2)에 `ads.txt`와 소유 확인 태그가 올라가 있다. 사용자가 애드센스에서 소유 확인과 심사 신청을 마쳤고, 결과를 기다린다(보통 며칠~2~4주, 메일로 옴).
- 박물관·`warehouse-tycoon`의 광고 칸 코드는 각 저장소 main에 push했지만 **배포하지 않았다.** 두 저장소에는 아직 `ADSENSE_*` 변수가 없어서 배포해도 광고가 나오지 않는다.

**심사에 떨어지면**: 사유를 받아 보완한다. "콘텐츠 부족"이면 home의 `/now`나 소개 글을 늘리고 다시 신청한다.

**심사에 붙으면** (사용자가 새 대화에서 "애드센스 심사 붙었어"라고 하면 여기부터):

| 순서 | 누가 | 할 일 |
|---|---|---|
| 1 | 사용자 | 애드센스 **광고 → 사이트별 → 자동 광고** 끄기 |
| 2 | 사용자 | **개인 정보 보호 및 메시지**에서 유럽 동의 메시지 켜기 |
| 3 | 사용자 | **광고 → 광고 단위 기준 → 디스플레이 광고**로 광고 단위 3개를 만들고 ID 전달: 박물관 핀보드용, 박물관 도록·야간용, 창고 타이쿤 사이드바용 |
| 4 | 에이전트 | `gh variable set`으로 입력. `BranKein/vibe-museum`: `ADSENSE_CLIENT=ca-pub-6463808305479933`, `ADSENSE_SLOT_INFEED`(핀보드), `ADSENSE_SLOT_DISPLAY`(도록·야간). `BranKein/vibe-warehouse-tycoon`: `ADSENSE_CLIENT`(같은 값), `ADSENSE_SLOT_SIDEBAR` |
| 5 | 에이전트 | 사용자에게 확인받고 배포 태그 push: 박물관 `v0.0.5`, `warehouse-tycoon` `v1.0.8`(그 사이 다른 배포가 있었으면 다음 번호) |
| 6 | 에이전트 | 배포 뒤 실제 사이트에서 스크립트·칸이 들어갔는지, 콘솔 에러가 없는지 확인. 실제 광고가 채워지기까지는 몇 시간 걸릴 수 있다 |

## 사용자가 할 일

1. 애드센스에서 광고 단위(디스플레이 광고)를 칸마다 만들고 ID를 에이전트에게 전달 → 에이전트가 Variables 입력.
2. 배포 태그 push(요청하면 에이전트가 한다).
3. "개인 정보 보호 및 메시지"에서 유럽 동의 메시지 켜기.
4. 게임 안 보상형 광고가 필요하면 H5 Games Ads를 따로 신청(승인 보장 없음).
